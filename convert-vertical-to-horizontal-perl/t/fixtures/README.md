# Synthetic parity fixtures

These 21 input EPUBs and expected outputs were generated by
`Test-EpubConversion.ps1` during its successful PowerShell reference run.
They contain synthetic sample text and binary bytes, not commercial books.

`manifest.json` records the expected classification and changed entry list.
The Perl suite compares every output payload and entry metadata against the
reference, then verifies an exact-copy second pass. ZIP compression streams are
allowed to differ between .NET and zlib.

The source generator covers horizontal English and Arabic, unused vertical CSS,
comments, CSS strings/custom properties, unrelated quoted HTML attributes,
EPUB 2/3 fixed layouts, image-only and image-dominated comics, SVG images and
live text, modern and legacy writing modes, imported CSS, inline styles,
UTF-8 BOMs, UTF-16, and long publisher comment sequences.
